# Roccia Compress Tools

Texture compressor for GTA V and FiveM assets by Roccia Dev. It shrinks the textures inside .ytd, .ydr, .ydd and .yft files (DXT1, DXT5, BC7 and more, with four encoders to choose from) and shows you every texture before and after.

## Download

Get it from the [Dev Tools page on rocciadev.com](https://rocciadev.com/dev-tools.html) (sign in first). It is a single portable file, no installer.

You need:

- Windows 10 or 11, 64-bit
- [.NET 8 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0)
- A [rocciadev.com](https://rocciadev.com/) account with credits. The app signs you in through your browser the first time and remembers you after that.

Credits are charged per texture (or per file, depending on the current pricing) right before each file is processed, and the app shows the estimated cost before it starts.

## Updates

The app checks for a new release every time it starts. When one is out, an **Update** button appears next to the Website button: one click downloads it, checks it against the published checksum and restarts the app.

Help: [rocciadev.com/support.html](https://rocciadev.com/support.html) and [Discord](https://discord.gg/hrUFC6ydPZ).
